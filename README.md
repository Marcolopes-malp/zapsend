# 🚀 LeadZap - Disparo Rápido de WhatsApp para Leads

Aplicação web ultra-intuitiva e rápida desenvolvida em **Next.js** + **TypeScript** para envio direto e ágil de mensagens para novos leads no WhatsApp.

## 🎯 Funcionalidades

- **Campo de Telefone Inteligente**: Máscara automática brasileira `(DD) 9XXXX-XXXX`.
- **Campo de Mensagem Editável**: Mensagem fixa configurada pré-carregada, permitindo edição a qualquer instante.
- **Disparo com 1 Clique ou Enter**: Ao pressionar `Enter`, abre instantaneamente o WhatsApp com a mensagem formatada para o lead.
- **Histórico no Navegador**: Salva os últimos envios direto no `localStorage` sem precisar de banco de dados.
- **Pronto para Deploy na Vercel**: 100% otimizado para deploy gratuito e serverless na Vercel.
- **Rota API Extensível**: Rota `/api/send` pronta caso deseje no futuro integrar com Evolution API, Z-API ou Meta Cloud API.

## 🛠️ Como Rodar Localmente

1. Abra o terminal na pasta do projeto:
```bash
cd "C:\Users\Lenovo\Documents\whatsapp-lead-sender"
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
👉 [http://localhost:3000](http://localhost:3000)

## ☁️ Como Fazer o Deploy na Vercel (Gratuito)

### Opção 1: Via GitHub (Recomendado)
1. Suba esta pasta para um repositório no seu GitHub.
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New... > Project"**.
3. Importe o repositório.
4. Clique em **"Deploy"** (o Next.js é detectado automaticamente sem necessidade de configurações adicionais).

### Opção 2: Via Vercel CLI (Direto do Terminal)
1. No terminal do projeto, execute:
```bash
npx vercel
```
2. Siga as confirmações rápidas e sua página estará online em segundos!
